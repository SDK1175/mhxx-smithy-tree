# MHXX Smithy Tree

[MHXX Recomp](https://github.com/SDK1175/MHXXRecomp)(몬스터헌터 더블크로스 PC 포트)용 대장간 모드입니다. 대장간 무기·방어구 목록을 파생 트리와 상세 카드로 보여 주고, 위시리스트를 지원합니다.

## 기능

- **무기 파생 트리**: 레어도 칸, 파생 레벨 표시, 보유 장비 체크, 열쇠 소재를 못 찾은 무기는 `?` (스포일러 방지, Y로 켜고 끄기)
- **상세 카드**: 공격력, 회심률, 속성, 슬롯, 예리도(장인 증가분 포함), 레벨별 이름, 생산·파생·강화 소재와 보유 수
- **방어구 그리드**: 하위 / 상위 / G급 탭, 시리즈 × 5부위, 방어력, 내성, 스킬, 생산 소재
- **생산 확인**: A → 확인 창 → "생산한다"로 게임의 생산을 그대로 진행
- **위시리스트**: ZR 하나 담기, ZL 파생 경로 / 방어구 세트 전체 담기, R로 열기 (달성률, 필요 소재 합계, 다 모이면 알림)
- 아이콘과 이름은 플레이어의 게임 파일에서 그때그때 읽어 옵니다. 모드에는 게임 데이터가 들어 있지 않습니다.

## 조작

| 키 | 동작 |
|---|---|
| 십자키 / 스틱 | 커서 이동 |
| A | 생산 / 강화 |
| B | 뒤로 |
| L | 레벨 (무기) / 랭크 (방어구) |
| Y | 스포일러 방지 켜기 / 끄기 |
| ZR / ZL | 위시리스트 담기 / 경로·세트 전체 담기 |
| R | 위시리스트 열기 |

## 설치

1. MHXX Recomp **0.10.14 이상**이 필요합니다.
2. 릴리즈의 압축 파일을 풀어 `mods` 폴더에 넣습니다:
   `mods/mhxx-smithy-tree/romfs/nativeNX/plugins/mhxx_smithy_tree.nro`

## 알려진 한계

- 위시리스트는 게임을 끄면 초기화됩니다.
- 장비 강화 목록에서 A를 누르면 게임 원래 화면으로 넘어갑니다.

## 빌드

`./build.sh` (clang, ld.lld, python3). 결과: `build/mhxx_smithy_tree.nro`
