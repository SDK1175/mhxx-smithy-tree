# MHXX Smithy Tree 0.13.1

## 고친 점

- **퀘스트를 다녀오면 이름이 `#번호`로 나옴:** 모드가 이름 데이터(`table\weaponNNMsgData_jpn`, `armorSeriesData_jpn` 등)의 메모리 위치를 한 번 찾으면 계속 기억해 둠(`find_res`의 slot). 퀘스트를 다녀오면 게임이 그 데이터를 내렸다가 다른 위치에 다시 올리는데, 모드는 옛 위치를 계속 읽어서 이름을 못 찾음. 옛 위치에 다른 데이터가 들어오면 엉뚱한 글자나 튕김도 가능.
  - 로그(0.13.0): 50초에 weapon07MsgData를 찾음(762개) → 340~420초 마을 퀘스트 → 4134초 다시 대장간: 태도 이름이 전부 `#번호`. 퀘스트 전에 열지 않은 다른 무기는 퀘스트 뒤에 처음 찾아서 멀쩡함.
  - 고칠 방법: 대장간에 들어갈 때마다(화면이 대장간 밖 → 안으로 바뀔 때) 이름 데이터 위치(무기·아이템·방어구·스킬)를 모두 버리고 다시 찾기.
